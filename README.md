# Campus Notes – VCS Assignment

## About the Project
This repository contains programming practice files and study materials created as part of the Version Control Systems (VCS) assignment.

## Repository Contents

| File | Description |
|---|---|
| `fibonacci.py` | Python program to generate the Fibonacci sequence |
| `reverse_string.py` | Python program to reverse a string |
| `oop.txt` | Notes related to Object-Oriented Programming |
| `README.md` | Project overview and documentation |

## Technologies Used
- Python
- Git
- GitHub
- Markdown

## How to Use
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the Python files using Python.

Example:

```bash
python fibonacci.py
python reverse_string.py
```

## Purpose
The purpose of this repository is to organise programming practice materials and understand Git and GitHub collaboration, including branching, commits, pull requests, and code reviews.
